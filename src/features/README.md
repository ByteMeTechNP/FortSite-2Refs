# Feature modules

Future product domains live under `src/features/<domain>/`.

Each feature owns its own components, hooks, adapters, types, and tests when those pieces exist. Shared presentation primitives and generic loading, empty, and error states stay under `src/components/`. Shared configuration stays under `src/config/`.

Phase 02 does not add any business feature. Do not create empty placeholder feature folders for projects, BOQ, marketplace, accounting, or other modules until their phase starts.
